The Cave 3.3.3 - limited regression-tested patch
Date: 2026-10-31
Source: the supplied MAIN the-cave_3.3.2.zip
Source SHA256: 374386ff505777b05abbed02c0c975708f7bd548252680477660c06110e77bb7

Scope
-----
This release addresses three reproduced defects only:
1. Collapse support caches can retain a removed force after a native force merge.
2. Partial Store Box and legacy belt transfers can replenish ammunition or
   durability when the old implementation manually adjusts a source stack.
3. Uranium and Mineral information panels exceed the native 500-character limit
   and lose their final warnings.

Runtime changes (exactly five Lua files)
---------------------------------------
control.lua: invalidate the mirror and collapse caches before force-merge
lifecycle cleanup.
scripts/collapse.lua: also invalidate the same-tick reach cache in wipe_cache.
These are derived, module-local caches. No persistent job, countdown, render
object or surface is removed. This does not assume native merges union research.

scripts/cave_item_boxes.lua: use native transfer_from_stack for each existing
inventory slot and legacy transport-line stack; retain direction, slot order,
blocked-transfer behavior and existing migration routing.

scripts/uranium_caves.lua and scripts/mineral_caves.lua: shorten only their
information-text builders. Keep the existing per-record duration calculations,
resource/Bob branches, final-five-minute access and death/sealing warnings.
Existing configuration-change handling refreshes valid panels in place.

Other changed files: info.json (version only), README.md, changelog.txt.
New file: this report. No existing file was removed.
Settings/defaults, balance, prototypes, research, resources/rewards, assets,
locales and historical migrations are unchanged. The No Space Age edition is
unchanged. Old TESTING documents describe their original releases.

Limits and known unchanged issues
--------------------------------
These results support this small patch; they do not guarantee all possible
game states. No graphical client rendering, connected-client multiplayer or
long-duration live campaign was tested. Some player actions use documented
fixture wrappers; native forces/entities/inventories/save files are real.
Bob conditional panel wording used an explicit API double, not a full Bob mod
integration run. Third-party mod combinations outside the fixtures are untested.

Previously reported issues outside these three fixes remain unchanged:
- Resetting the owning team on shared original Nauvis can reset the other team's
  world-level collapse/evolution state.
- The small Gleba-spawner custom reward callback uses the wrong prototype name.
- Other stale tooltip/locale/help strings were not revised in this patch.
- The prior Gleba collision-mask warning still occurs with full Space Age and
  Everything On Nauvis; it is not a newly introduced warning.

The separate QA archive contains fixtures, commands, before/after results,
manifests and logs, including the final packaged-ZIP smoke-test result. Do not
install that QA archive as a mod. This release archive contains no QA hooks.
Keep a copy of your current save before upgrading and use matching mod versions
on server and clients.
